# Python-Repo-Assignment-3
Task 1:This program defines a recursive function called "factorial" that calculates the factorial of a number.
If the number is 0 or 1, the function returns 1 as the base case; otherwise, it multiplies the number by the factorial of the previous number.
The user is asked to enter a number, which is passed to the function.
Finally, the program prints the factorial of the entered number.

Task 2:This program imports the "math" module to use mathematical functions.
The function "ask_user_no" takes a number and calculates its square root, natural logarithm, and sine.
The user enters a number, which is passed to the function and the results are returned as three values.
Finally, the program prints the calculated square root, logarithm, and sine of the number.
